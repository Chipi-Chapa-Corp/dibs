# Это моя игра

The Russian-language game played on 7 November 2026: three boards with 103 tiles, followed by seven final categories with one question each. It includes picture and music questions, hidden modifiers and Daily Doubles.

To play, choose **Create game → Import JSON**, select [eto-moya-igra.json](eto-moya-igra.json), then create the game. This starts a fresh copy with no players, scores or previously played questions.

The 75 referenced media files are bundled in `public/played-games/eto-moya-igra/`. They work with this repository in development and production builds. If moving the JSON to another Dibs installation, copy that folder into the same location under its `public/` directory.

Question notes retain source links and host guidance. External source links remain external. This export includes questions, answers, settings and appearance; the original session's player identities, credentials and results are not included.
